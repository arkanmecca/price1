# أركان مكة — التسعيرة السريعة

منظومة محلية مستقلة للتسعير السريع، تعمل مباشرة من المتصفح وتحفظ التسعيرات وإعدادات سعر الصرف على الجهاز عبر `localStorage`.

## الاستخدام

افتح رابط GitHub Pages، أدخل بيانات التكلفة، ثم احفظ التسعيرة محلياً أو انسخها أو أنشئ بطاقة مشاركة.

> التسعيرات محفوظة في المتصفح والجهاز الحاليين فقط. مسح بيانات الموقع يؤدي إلى حذفها.

تعرض نسخة الهاتف شريطاً صغيراً للشعار والقائمة، بينما تبدأ نسخة الكمبيوتر مباشرة بمحتوى التسعير دون شريط حساب أو تحديث زائد.
