# أركان مكة — التسعيرة السريعة

منظومة محلية مستقلة للتسعير السريع، تعمل مباشرة من المتصفح وتحفظ التسعيرات وإعدادات سعر الصرف على الجهاز عبر `localStorage`.

## الاستخدام

افتح رابط GitHub Pages، أدخل بيانات التكلفة، ثم احفظ التسعيرة محلياً أو انسخها أو أنشئ بطاقة مشاركة.

> التسعيرات محفوظة في المتصفح والجهاز الحاليين فقط. مسح بيانات الموقع يؤدي إلى حذفها.

تعرض نسخة الهاتف شريطاً صغيراً للشعار والقائمة، بينما تبدأ نسخة الكمبيوتر مباشرة بمحتوى التسعير دون شريط حساب أو تحديث زائد.

تكلفة السرير الإضافي منفصلة بين مكة والمدينة، ويُحتسب كل سعر وفق عدد ليالي المدينة المقابلة.

يمكن إضافة حتى 30 بند تكلفة ديناميكياً، مع اسم ومبلغ وعملة لكل بند، ويحوّل النظام الريال والدولار إلى الدينار تلقائياً.

تظهر التأشيرة وتذكرة السفر والنقل دائماً تحت الفنادق كتكاليف أساسية ثابتة غير قابلة للحذف. ويمكن حفظ أي بند إضافي جديد بالمبلغ والعملة لاستخدامه في التسعيرات التالية، أو تحديثه وحذفه لاحقاً.

يُحدَّد عدد الأسرّة الأساسية والإضافية لكل نوع غرفة. إجمالي النزلاء المستخدم في توزيع التكلفة يساوي مجموعهما؛ فالغرفة الثلاثية مع سرير إضافي واحد تُحسب على 4 نزلاء.
